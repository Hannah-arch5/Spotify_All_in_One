## Do Not Break

These behaviors are required by Codex's transcript workflow:

1. Download transcript JSON files into:
   `/Users/hannah/Downloads/Spotify Transcript Collector/`

2. Preserve these JSON fields:
   - `source`
   - `capturedAt`
   - `spotifyEpisodeId`
   - `episodeUrl`
   - `podcastName`
   - `episodeTitle`
   - `publishedDate`
   - `transcriptLanguage`
   - `isAutoGenerated`
   - `segments`
   - `raw` when source is `spotify_api`

3. Preserve `segments` shape:
   - `start`
   - `end`
   - `timestamp`
   - `speaker`
   - `text`

4. Keep API transcript capture and visible transcript/manual download both working.

5. Keep the route-safety behavior:
   If Spotify preloads a transcript for an episode that is not the current browser URL, cache it and process it only when the route matches.

6. Do not treat Spotify API speaker title blocks such as `Speaker 1` as transcript text.

7. Keep timestamp parsing compatible with:
   - `0:16`
   - `12:34`
   - `1:24:37`

## Recovery

If later plugin changes break transcript collection, restore the stable version with:

```bash
git checkout STD_v2.0 -- chrome-spotify-transcript-downloader
```

To inspect what changed after `STD_v2.0`:

```bash
git diff STD_v2.0 -- chrome-spotify-transcript-downloader
```

Before changing the plugin, create a branch or commit first so the working version is easy to compare.
