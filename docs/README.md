# Docs

This folder keeps project notes out of the repository root.

## Folders

- `gemini/`: Gemini report generation protocol, review checklist, and final prompt template.
- `research/`: Transcript source experiments and YouTube / Language Reactor feasibility notes.
- `workflow/`: Overall podcast intelligence workflow design.
- `plugin/`: Guardrails for Antigravity or other tools modifying the Spotify Transcript Downloader extension.

Keep root-level files limited to:

- `README.md`
- `PROJECT_MEMORY.md`
- project configuration and code folders
