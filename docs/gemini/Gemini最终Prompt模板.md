# Gemini 最终 Prompt 模板

请按照我提供的 `Episode Manifest`、`Transcript Evidence Pack` 和必要背景资料，生成本次最新播客情报研报。

## 总要求

- 最新研报只包含本次 `Episode Manifest` 中列出的 episode。
- 不要补充之前的内容，也不需要保留以前的内容。
- 第二部分的顺序必须严格按照 `Episode Manifest` 顺序排列；该顺序已按 episode 发布时间倒序排列，最新发布时间在前。
- 必须基于真实的播客内容、完整节目文稿 transcript / YouTube 字幕 / 官网 transcript，以及可靠背景资料，为我提供针对实际内容的深度分析。
- 不要根据标题、截图、简介中的几行文字进行内容推理。
- 严格基于检索到或提供的真实数据进行筛选，杜绝任何虚构或基于未来的模拟推演。
- 研报的分析精细程度要非常高。

## 输入材料说明

你将收到：

1. `Episode Manifest`
   - 本次研报唯一允许纳入的 episode 清单。
   - 包含标题、播客名、发布时间、原始链接、transcript 来源。

2. `Transcript Evidence Pack`
   - 每个 episode 对应的底层逐字稿、YouTube 字幕、官网 transcript 或 Language Reactor 提取字幕。
   - 你必须优先基于这些材料写第二部分。

3. 可选背景资料
   - 你可以调取相关宏观事实、公司背景、技术背景、产业背景、人物背景来完成深度解析。
   - 背景资料必须服务于 episode 的实际内容方向。

## 数据源与真实性规则

- 不允许纳入 `Episode Manifest` 之外的任何旧节目或相似节目。
- 不允许根据标题自行推断节目内容。
- 不允许把背景资料写成播客嘉宾的原话或观点。
- 播客事实、关键观点、嘉宾论述、金句必须来自 transcript / 字幕。
- 背景资料可以用于解释“为什么重要”，但必须与播客内容方向一致。
- 如果某个 episode 没有明确底层逐字稿，只能做“背景型有限分析”，并明确标注：

> 本 episode 未取得明确底层逐字稿，以下仅基于官方简介、原始链接与相关背景资料作有限分析，关键事实需复核。

- 缺少 transcript 的 episode 不得编造核心原话。

## 输出结构

### 第一部分：摘要与总结

约 700 字。

必须包含：

- 中文标题
- 英文标题
- 本次研报覆盖 episode 数量
- 本次播客更新共同呈现出的核心趋势
- 对科技、AI、商业、资本或宏观环境的整体判断

### 第二部分：前沿情报深度梳理

请针对 `Episode Manifest` 中的每一篇播客或视频，严格按顺序逐一输出。

每篇按以下结构：

#### 情报 N：[自拟情报标题]

- 原始标题：[使用 Manifest 中的准确原标题]
- 来源与发布者：[平台名称] | [频道/播客名] | [核心主讲人及其职位；如果 transcript 中无法确认，写“未在 transcript 中明确”]
- 原始链接：[使用 Manifest 中提供的准确 Spotify / YouTube / 官方页面链接]
- Transcript 来源：[YouTube 字幕 / 官网 transcript / Language Reactor / Spotify transcript / 缺失]
- 核心内容摘要：严格约 600 字。请详细梳理其探讨的技术细节、逻辑框架或核心观点；专业词汇和核心观点要有英文原文对照或解释。
- 情报价值点：说明该内容为何重要，解决了什么痛点，或预示了什么趋势。
- 关键金句 / 结论：提取 2 条最具洞见、有意义、可独立阅读的原话或接近原文的核心结论，并提供中文翻译或解释；不要在这一部分写时间戳、Speaker 1、发言者 1、Timestamp 等证据标记。时间戳只放在后面的“证据锚点”部分。
- 证据锚点：列出至少 3 个 transcript 时间戳或字幕片段位置；如果 transcript 缺失，写“无明确 transcript，待复核”。

### 第三部分：深度专题分析

围绕本次全部 episode 中反复出现的主题，进行跨节目分析。

要求：

- 必须指出支撑每个专题的 episode。
- 可以引入宏观事实和背景资料。
- 不得把单一 episode 的观点扩大成全行业定论。

### 第四部分：深度洞察与第二层思维

请输出更高层的判断，包括但不限于：

- 技术范式变化
- AI 与软件商业模式变化
- 硬件、能源、算力或基础设施约束
- 资本市场信号
- 监管、社会结构或地缘影响
- 对创业者、投资者、产品经理、研究者的启示

要求：

- 每条洞察必须能回到至少一个 episode 的具体内容。
- 可以进行合理推演，但必须标明“可能意味着”“这提示”“可以理解为”等分析性措辞。

### 第五部分：结论与战略意义

总结本次播客更新对科技、AI、商业、资本和社会趋势的战略意义。

## 风格要求

- 输出语言：中文为主，必要处保留英文原文、英文术语或英文标题。
- 检索和背景参考范围：全球，重点关注硅谷英文语境下的原生内容。
- 风格：高密度、专业、清晰、具有科技情报分析感。
- 避免空泛宏大叙事，每个判断都要尽量有具体内容支撑。

## 最终自检

提交前请自检：

- episode 数量是否与 `Episode Manifest` 完全一致。
- 第二部分顺序是否与 `Episode Manifest` 完全一致。
- 是否出现 Manifest 之外的旧节目或相似节目。
- 每篇是否都有准确标题、来源、链接。
- 每篇是否标注 transcript 来源。
- 有 transcript 的 episode 是否有时间戳证据锚点。
- 缺少 transcript 的 episode 是否明确标注“有限分析 / 待复核”。
- 背景资料是否被清楚地区分为背景，而不是播客原话。
- 是否存在没有来源支撑的人名、公司名、金额、日期、产品名或结论。
